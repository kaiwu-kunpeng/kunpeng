# localfs 授权与安全边界

localfs 是鲲鹏对话与 agent 访问用户本机指定目录的通道。
它让运行在服务端工作区的 agent 通过浏览器读取、列目录、写入、建目录或删除已授权目录中的内容。
localfs 与 agent 自带的服务器文件工具不是同一套通道：前者操作浏览器所在机器，后者操作服务端工作区。

## 何时使用

只有当用户明确点名“我的本地目录”“我电脑上的文件”或“已授权目录”时，agent 才应使用 localfs。
普通仓库任务继续使用工作区文件工具，不能因为 localfs 可用就自动扫描用户电脑。
每次授权只覆盖用户在浏览器目录选择器中选中的根目录，不代表授权整台机器。
工具路径必须是相对路径，不能用绝对路径或 `..` 越出授权根。

## 授权模型

用户在桌面版 Chrome 或 Edge 中点击“授权本地目录”，由浏览器显示原生目录选择与读写授权界面。
目录句柄保存在浏览器本地，并按“登录账号 + 会话”分键；其他账号或其他会话不会自动继承。
服务端登记信息保存在 `<stateDir>/localfs-authz.json`，文件名关键串是 `localfs-authz`。
登记项包含会话、浏览器 clientId、目录名、来源、账号和时间戳，但不包含目录文件内容。

登记项的 TTL 为 7 天。
serve 启动时会加载未超过 7 天的条目，过期条目被丢弃；浏览器端仍需持有有效目录句柄和权限才能真正执行文件操作。
serve 重启后，保持打开且已授权的页面会继续轮询并自愈重报授权；为限制重复登记，重报间隔不超过 60 秒一个周期。
如果页面已关闭、浏览器权限被撤销或目录句柄失效，服务端登记本身不能恢复文件访问。

## owner 归属校验

localfs 将授权绑定到具体会话、浏览器 clientId 和登录账号。
轮询与结果回传必须来自登记的浏览器 clientId；agent 发起操作时，当前账号也必须与登记 owner 一致。
归属不匹配时服务端返回 `403 not-owner`，页面不会接管另一个来源或机器已经授权的目录。

设置 `KP_LOCALFS_STRICT_OWNER=1` 会关闭缺少登记项时的旧兼容回退，要求 owner 登记存在后才允许相关通道工作。
面向多人、远程访问或生产环境的 serve 应启用该严格模式，并同时启用驾驶舱认证。
该环境变量不能替代浏览器授权；两层校验必须同时成立。

## 为什么有“一键恢复”

浏览器可以记住目录句柄，但出于 Web 安全模型，刷新页面、重启浏览器或重启 serve 后，读写权限可能需要新的用户手势。
因此页面会先查询既有句柄权限：仍有效时直接恢复，需确认时显示“恢复 <目录名>”。
用户点击一次后，浏览器调用权限请求；若浏览器不再认可旧句柄，则重新打开原生目录选择器。
这个入口是对浏览器权限生命周期的显式处理，不是绕过操作系统权限。

## 用户注意事项

- 只授权当前任务真正需要的可信目录，优先新建范围较小的交换目录。
- 不要授权主目录、密码库、SSH 配置、云盘根目录或包含大量无关隐私的上级目录。
- localfs 支持写入和删除；在要求 agent 批量改动前，先备份重要文件。
- 页面显示的目录名和 `@来源主机` 应与预期一致；出现“另一来源/机器授权”警告时先核对设备。
- 异地通道必须由用户明确点名才使用，不能把本地工作区请求擅自解释成远端电脑请求。
- 对话中不要发送密钥、口令或无关敏感文件来“测试授权”。
- 手机和平板浏览器不支持该目录授权流程，应使用桌面版 Chrome 或 Edge。

## 如何撤销授权

1. 在对应对话的目录标签上点击 `×`，停止该页面轮询并删除浏览器中该账号、该会话保存的目录句柄。
2. 在浏览器站点权限中撤销该站点的文件系统访问；需要彻底清理时，同时清除该站点的本地数据。
3. 关闭仍打开的同来源页面，避免旧页面继续持有内存中的目录句柄。
4. 如需立即删除服务端登记元数据，先停止 serve，再从 `<stateDir>/localfs-authz.json` 删除对应会话条目，确认 JSON 仍为合法数组后重启。

仅删除 `localfs-authz.json` 的登记并不会替用户清除浏览器权限；仅清浏览器句柄也可能让服务端元数据保留到 TTL 到期。
完整撤销应同时处理浏览器访问能力和服务端登记。

## 异常排查

- 显示“目录授权已失效”：点击目录标签重新授权，确认操作系统未移动或删除该目录。
- 返回 `not-owner`：确认当前登录账号、会话和浏览器设备与最初授权一致，不要复用他人的会话链接。
- serve 重启后短暂无响应：保持页面打开，等待最多 60 秒的授权重报周期；仍失败则手动点“恢复”。
- agent 报“未授权目录”：回到发起该对话的浏览器授权，不要让 agent 静默改用服务器文件工具。

安全边界的核心是：用户明确选定最小目录，浏览器保管真实句柄，服务端只把操作交给匹配的 owner。
