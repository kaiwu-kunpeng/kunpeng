# 鲲鹏帮助中心

这里是鲲鹏面向终端用户的帮助文档入口。

如果你第一次接触鲲鹏，建议按“新用户上手”的顺序阅读；已经完成安装的用户可以直接查找日常操作或管理员运维主题。

## 新用户上手

本辑包含以下 5 篇：

1. [鲲鹏是什么](01-getting-started/what-is-kunpeng.md)：了解产品定位、要解决的问题与北极星指标。
2. [核心概念](01-getting-started/core-concepts.md)：理解方案、验收、flow、loop、人工门、宪法与差分验证。
3. [安装与运行](01-getting-started/install-and-run.md)：准备环境、构建命令行工具并启动总控台。
4. [5 分钟跑通第一个项目](01-getting-started/first-project.md)：登记目标仓库、接管项目并提交第一份方案。
5. [总控台导览](01-getting-started/cockpit-tour.md)：按真实侧栏认识各个入口。

推荐阅读顺序：先了解“鲲鹏是什么”和“核心概念”，再完成“安装与运行”及“第一个项目”，最后通过“总控台导览”熟悉日常入口。

## 使用文档时的约定

命令中的 `<目标仓库路径>`、`<spec.md>` 等内容是占位符，执行时请替换为你自己的路径。

帮助文档只描述仓库中已经存在的命令和页面；若文档与实际版本不一致，请以当前版本的 CLI 帮助和总控台界面为准。
