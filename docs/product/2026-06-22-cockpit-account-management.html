鲲鹏 Cockpit · 账号管理

产品文档 ｜ 2026-06-22 ｜ 设置页·Web 用户增删改 + 分组手风琴

一句话

cockpit 设置页现在能完整管理 Web 登录账号——增、删、改（改名 / 切角色 / 改 profile / 重置密码），并把设置页五组内容做成可折叠手风琴，默认只展开「账号」，一屏清爽。仅 owner 角色可操作。

能做什么

能力说明
查看账号列出所有 Web 用户：用户名 · 角色 · profile（项目隔离标识）。
添加账号填用户名 / 初始密码 / 角色（owner｜member）/ profile，一键新增。
编辑账号（本次新增）每行「改」按钮 → 内联面板，可改用户名、切角色、改 profile、重置密码（密码留空则不改）。
删除账号每行「删除」按钮，带二次确认。
改我的密码当前密码 + 新密码，改自己的登录密码（不影响他人）。

角色与项目隔离

  • owner 管理员：可管理所有账号（增删改）。
  • member 成员：受限，只能访问分配给它的 profile（登录即场景隔离，互不串项目）。

防脚枪守卫

账号是登录凭据，误操作会把人锁在门外。系统内建以下守卫：

  • 不能删除 / 降级最后一个 owner——避免系统再无管理员、永久锁死。
  • 不能删除当前登录的自己——即便存在第二个 owner 也拦下（防 UI 脚枪）。
  • 改名碰撞拒绝——新用户名若与已有账号重名，拒绝。
  • 越权拦截——member 调用任何账号管理接口一律 403。

设置页手风琴

设置页五组——账号 / 通讯·远程批门 / 后端路由 / 运行状态(只读) / 偏好——每组标题带 ▸/▾ 箭头，点标题展开或收起。进页面默认只展开「账号」，其余收起，避免一长条全摊开要翻半天。

怎么用

  1. 以 owner 账号登录 cockpit。
  2. 左侧导航进「设置」，「账号」组默认已展开。
  3. 添加：底部表单填好 → 「添加账号」。
  4. 编辑：某行点「改」→ 改字段 → 「保存修改」。
  5. 删除：某行点「删除」→ 确认。
边界：这是个人多工作区的账号能力（自用、自己的凭证、项目互不冲突），不是对外 SaaS 的用户系统。远程访问见运维笔记 docs/runbooks/cockpit-remote-access.md。
